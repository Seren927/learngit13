# 社区协作说明

OpenRepoLens 采用轻量、透明的个人开源项目治理方式。所有规则、代码与变更记录都保留在公开仓库中，便于使用者理解结论来源。

## 讨论渠道

- **Issue**：报告缺陷、提出检查规则建议、讨论使用问题。
- **Pull Request**：提交经过测试的代码或文档变更。
- **Security**：安全问题按照 `SECURITY.md` 私下报告，不进入公开讨论。

## 角色与权限

- **维护者**：负责 Issue 分类、Pull Request 审查、版本发布和安全响应。
- **贡献者**：提交 Issue、文档、测试或代码，参与技术讨论。
- **使用者**：运行工具、反馈误判并提出适用场景建议。

当前项目由课程学生郑骞欢维护。长期发展时可在 `MAINTAINERS.md` 中增加共同维护者并明确审查责任。

## 审查与合并

每个 Pull Request 至少完成一次自检：说明变更目的、列出测试结果、确认不包含敏感信息。维护者会关注行为兼容性、规则可解释性和文档同步情况。合并前优先使用功能分支，合并后删除临时分支。

## 发布节奏

当前按课程实践阶段发布里程碑版本。正式版本号使用语义化版本，并在 `CHANGELOG.md` 中记录新增、修复与已知限制。
